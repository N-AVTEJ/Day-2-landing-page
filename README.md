## 📖 Overview

**NEXORA** is a sleek, modern, high-converting landing page built for modern SaaS products and AI-powered productivity platforms. Designed from scratch using **Vanilla HTML5, modern CSS3, and ES6+ JavaScript**, this project demonstrates modern web design aesthetics—featuring rich glassmorphism, fluid micro-interactions, responsive typography, and accessible interactive widgets without relying on heavy frameworks.

Part of the **100 Web Development Projects Challenge** (Day 2).

---

## ✨ Key Features

- 🎨 **Modern Design & Visual Hierarchy**
  - Ultra-modern dark-accented glassmorphism aesthetic with tailored violet/indigo gradients.
  - Custom typography pairing utilizing Google's **Plus Jakarta Sans**.
  - Pure CSS Application Mockup preview complete with browser chrome, active copilot status, sidebar navigation, and kanban sprint cards.

- 📱 **Mobile-First & Fully Responsive**
  - Smooth-sliding mobile drawer navigation with animated hamburger toggle.
  - Backdrop dimming with click-outside and `Escape` key dismissal.
  - Fluid grid layouts adapting seamlessly across mobile, tablet, and desktop viewports.

- ⚡ **Interactive Components & UI Enhancements**
  - **Interactive Dashboard Preview Tabs**: Dynamic tab switcher revealing Kanban sprint boards, AI copilot insights, timeline roadmaps, and analytics.
  - **Scroll Spy Navigation**: Real-time active navigation link indicator powered by `IntersectionObserver`.
  - **Accessible Accordion FAQ**: WAI-ARIA compliant FAQ accordion with animated expand/collapse states.
  - **Interactive Demo Modals**: Lightweight dialog modal for Sign In and Tier Selection with trap-focus handling.
  - **Sticky Header & Back-To-Top**: Dynamic header styling on scroll and floating smooth back-to-top button.

- ♿ **Accessibility & SEO Optimized**
  - Semantic HTML5 structure (`<header>`, `<nav>`, `<main>`, `<section>`, `<aside>`, `<footer>`).
  - Open Graph & Twitter Card social meta tags.
  - Accessible skip-to-content link, `aria-expanded`, `aria-controls`, and `prefers-reduced-motion` compliance.

## 🚀 Getting Started

No build steps, bundlers, or package installations are required! Run it immediately in any modern browser.

### Prerequisites

All you need is a modern web browser (Google Chrome, Firefox, Safari, Microsoft Edge).

### Installation & Local Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/N-AVTEJ/Day-2-landing-page.git
   ```

2. **Navigate into the project directory:**
   ```bash
   cd Day-2-landing-page
   ```

3. **Open the project:**
   - Double-click `index.html` to open directly in your web browser.
   - *Or* run a local development server using VS Code **Live Server** extension.
   - *Or* run via Python in your terminal:
     ```bash
     # Python 3.x
     python -m http.server 3000
     ```
     Then navigate to `http://localhost:3000` in your browser.
